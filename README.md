# 🚀 Quick Text Formatter & Cleaner

A lightweight, privacy-focused frontend web application designed to instantly format, clean up, and optimize messy plain text. Built entirely using HTML, CSS, and vanilla JavaScript, this app runs entirely in the user's browser with zero server latency.

## ✨ Features

- **Case Conversion:** Instantly convert text between `UPPERCASE` and `lowercase`.
- **Space Cleaner:** Remove accidental double spaces, line break issues, and trim trailing edges.
- **Real-Time Analytics:** Live tracking of both character count and word count as you type.
- **One-Click Copy:** Seamlessly copy your formatted text straight to your clipboard.
- **Privacy First:** Data never leaves your machine—no backend server tracking.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Custom Variables, Responsive Grid Layout)
- **Logic:** Vanilla JavaScript (ES6+)
- **Hosting:** Optimized for zero-cost static deployment on Vercel or Netlify.

## 🚀 Getting Started

### Local Setup
1. Clone or download this repository.
2. Open the `index.html` file in any modern web browser.
